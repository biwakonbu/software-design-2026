## PDFとSlidev

講義14PDF計377ページとA4冊子2PDF計67ページ、計 **444ページ**を出力した。PDFのページ数・サイズ・SHA-256は [pdf-manifest.json](pdf-manifest.json)。最終版の全ページをPNGへ再レンダーして目視検査し、本文、コード、表、図、改行、ページ番号を確認した。文字重なりや図表・コードの切れは見つからなかった。

第2回の見本は、実SlidevをIABで操作して確認した。IABの直接PDF表示が利用できなかったため、検査用のローカルPDF.jsビューアで実PDFデータを読み込み、ページ表示と次へ操作をComputer Useで確認した。元の大学資料を閲覧するChromeプロファイルには、この検査から操作していない。

最終共通スタイルは、段落・リストの行間、本文の濃さ、コードコメントのコントラスト、演算子の合字無効、カバーのフッター色を修正した。第2回の長い条件式は明示改行し、文字を縮小せずに配布時の表示互換性を改善した。

第02回と第14回の静的Slidevビルドを確認した。全14回はSlidev/ChromiumでPDF出力が成功している。

## 依存・公開検査

package-lock.jsonの依存は `npm audit --audit-level=low` で **0件**。dompurify、image-size、monaco-editorの修正版をoverridesで固定した。サンプルコードの実行には外部Pythonライブラリを必要としない。

公開対象を `scripts/check-public.py` で検査し、原資料、privateディレクトリ、個人のMacの絶対パス、大学システムのURL、secretパターン、想定外の画像・バイナリを除外した。画像は新作PDFの代表プレビューのみ。フォントのOFLライセンスを収録し、新作教材全体への包括的なライセンスは付与していない。

## CIと再現

[verify.yml](../.github/workflows/verify.yml)はPython3.12/3.14のテストとhost/meta比較、npm依存検査、全PDF出力、公開検査、全ページPNG生成を実行する。CIは作成済みの公開PDFとは別に、ソースとlockfileから出力を作り直す。

```sh
make test
npm ci
npx playwright install chromium
make export
make privacy
python3.12 scripts/render-pdfs.py
```

遠隔CIの結果はGitHub Actionsの実行履歴を参照する。自動テストやレイアウト測定だけでは、本文の理解しやすさや目視検査の代わりにならない。
