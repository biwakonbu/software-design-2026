# 第6回: 架空駅の経路探索演習

Python 3.12以上、標準ライブラリのみ。以下はリポジトリのルートから実行します。全て架空の駅・路線です。

| ファイル | 役割 |
| --- | --- |
| `route_data.py` | `GRAPH`と`STATIONS`、入力検査、CLI共通処理 |
| `route_starter.py` | **学生の実装練習用**。TODOのある未完成版 |
| `route_reference.py` | **公開解説・照合用**の完成例。提出物とは区別 |

モデルは無向・重みなし。A–B–DとA–C–E–D、孤立点Xがあり、各辺の移動を1回として最小化します。実路線の所要時間、運賃、乗換数は扱いません。

```sh
python3 examples/06-route-project/route_starter.py A B
python3 examples/06-route-project/route_reference.py A D
```

starterの既存動作は同駅`A A`なら`A`、隣駅`A B`なら`A -> B`。それ以外は`None`となる仮実装です。CLIも起動でき、多段の`A D`は「starterは多段経路未実装」と表示して終了コード2になります。これは仕様を満たす完成版ではありません。

両ファイルの関数契約は`find_route(graph, start, goal) -> list[str] | None`です。既知駅で到達不能は`None`、未知駅IDや無向辺の不整合は`ValueError`。グラフのキーは全ての駅、値は隣接駅IDのリストです。入力を変更しません。

CLIは`START GOAL`を受け取り、省略時は`A D`。成功は経路と`移動数: N`を標準出力へ出して終了コード0、入力エラー・経路なしは標準エラーへ出して終了コード2です。referenceの既定出力は次の通りです。

```text
A -> B -> D
移動数: 2
```

## 実装する部分

`exercises/06.md`の手順でstarterとデータを作業用フォルダへコピーし、その`find_route`をBFSへ拡張します。キュー、訪問済み記録、直前の駅を使い、最初に到達した終点から始点へたどって反転してください。隣接順を保てば同距離の経路も再現できます。`A A`、`A B`、`A D`、`A X`、未知IDをそれぞれ検証します。

公開テスト`python3 -m unittest discover -s tests -p test_foundations.py`はreferenceの最短性と**配布starterの既存動作**を検証します。作業コピーを自動採点するテストではありません。公開例を残し、作業フォルダに自分の完成仕様のテストを作ってください。referenceとの照合も自分の実装に適用できます。配布starterの未完成動作を確認するテストが通ることは、課題完成の証拠ではありません。

## 公開referenceの読み方・質疑

`previous`のキーは訪問済み駅を兼ね、キューへ入れる時に記録します。同じ駅を何度も追加することを防ぎ、始点からの距離が小さい順に処理されます。全駅数V、辺数Eに対して検査・探索ともO(V+E)。探索記録はO(V)、入力検査用の集合はO(V+E)です。

「なぜDFSではなくBFSか」「なぜ記録は取り出す時でなく入れる時か」「同駅と到達不能を区別できるか」「経路の全辺が入力に存在するか」「同じ長さならどれを選ぶか」を、自分のコードを追って説明してください。第7回の架空講評例では、到達できるだけの経路に対する反例を見ます。
