## B　注文集計

`submission/02/summary.py` に `summary(orders) -> int` を実装する。

- ordersは辞書のリスト。各辞書に `name`（文字列）、`price`、`quantity` を持つ。
- priceとquantityは0以上の整数。boolは受け付けない。
- 戻り値は円単位の整数。注文なしは0。
- キー不足・不正な型・負数には理由の分かる `ValueError` を送出する。
- 入力のリストや辞書を変更しない。

受入例：

```python
orders = [
    {"name": "ノート", "price": 200, "quantity": 2},
    {"name": "ペン", "price": 120, "quantity": 3},
]
assert summary(orders) == 760
assert summary([]) == 0
```

計算関数を作ってから、ファイル末尾の `if __name__ == "__main__":` でデモを表示する。解説例は `examples/02-basics/order_summary.py`。最初は自分で仕様を例にしてから参照する。
