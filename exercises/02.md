## 1．値と表示

```python
print(200)
print("200")
print(200 + 120)
```

**出力**：1行目が `200`、2行目も `200`、3行目が `320`。

`200` は整数の値、`"200"` は文字列の値です。画面では同じ形に見えても、できる操作は異なります。`200 + 120` は式で、計算すると値320になります。`print` は渡された値を画面に表示します。文字列の囲みの引用符は表示しません。

**確認**：`print("200" + "120")` の出力は？

**答えと理由**：`200120`。文字列どうしの `+` は連結なので、数の加算にはなりません。

## 2．代入と更新

```python
price = 200
original = price
price = price + 50
print(price)
print(original)
```

**出力**：`250`、`200`。

`=` は右辺を評価し、得たオブジェクトに左辺の名前を結び付ける代入です。`price = price + 50` は、更新前のpriceを使って250を計算してから、priceをその結果へ結び直します。originalの結び付きは変更していません。

**確認**：`original = price` は、今後もpriceの変更に追従する計算式を保存している？

**答えと理由**：いいえ。その時点でpriceが指す整数200へoriginalも結び付きます。後の代入はpriceという名前の結び付きを変更するので、originalは200のままです。リスト自体を変更する例は第9節で扱います。

## 3．型と変換

```python
text = "3"
count = int(text)
print(type(text))
print(type(count))
print(count + 2)
```

**出力**：`<class 'str'>`、`<class 'int'>`、`5`。typeの表示では、引用符内のstrやintが型の名前です。

型は、その値をどのように扱うかを決めます。よく使う型は、整数int、浮動小数点数float、文字列str、真偽値boolです。`int("3")` は文字列から整数への変換。元のtextは文字列のままです。変換は、任意の文字列で成功するとは限りません。

**確認**：`int("ノート")` は？

**答えと理由**：`ValueError`。intは文字列を整数の表記として解釈しますが、この文字列は整数を表していません。`input()` で受け取る値も文字列なので、数として使うときは変換と不正入力の扱いが必要です。

## 4．演算と優先順位

```python
print(2 + 3 * 4)
print((2 + 3) * 4)
print(7 / 2)
print(7 // 2)
print(7 % 2)
```

**出力**：`14`、`20`、`3.5`、`3`、`1`。

掛け算は加算より先に評価します。括弧を使うとまとまりを指定できます。`/` は通常の除算、`//` は床除算、`%` は剰余です。この正の整数の例では、7は「2を3回と、余り1」に分けられます。`//` は負数も扱う床除算なので、常に小数部分を0の方向へ切り捨てる説明にはしません。

**確認**：`6 / 2` の値と型は？

**答えと理由**：値は `3.0`、型はfloat。この整数同士の `/` もfloatを返します。注文課題で整数の単価・数量を使うときは、除算が必要かを先に考えます。

## 5．比較と条件

```python
quantity = 3
print(quantity == 3)
print(quantity > 3)
print(0 <= quantity < 10)
print(quantity != 0 and quantity < 5)
```

**出力**：`True`、`False`、`True`、`True`。

`==` は等しいかを比較し、`!=` は等しくないかを比較します。比較の結果は真偽値です。`and` を使うと、この例では両方の比較が成立する条件を作れます。`=` の代入とは使い方が異なります。

**確認**：quantityを0に変えた場合、最後の行は？

**答えと理由**：`False`。`quantity != 0` が成立しないためです。`and` は左辺が偽と判断できれば右辺を評価しません。Pythonのand自体は真偽値への変換結果ではなくオペランドを返しますが、ここでは比較式同士なので結果もboolです。

## 6．ifとインデント

```python
quantity = 0
if quantity > 0:
    print("注文あり")
else:
    print("注文なし")
print("確認終了")
```

**出力**：`注文なし`、`確認終了`。

条件が成立すればifの内側、成立しなければelseの内側を実行します。行頭の字下げでブロックを表します。最後のprintは字下げがないので、どちらの分岐でも実行します。字下げにはスペース4個を揃えて使いましょう。

**確認**：最後のprintをelseと同じ字下げにすると、quantityが2のときに何が変わる？

**答えと理由**：`確認終了` を表示しなくなります。最後のprintもelseのブロックへ入り、quantityが2ではそのブロックを実行しないためです。見た目の整形だけでなく、実行範囲が変わります。

## 7．forで合計する

```python
prices = [200, 120, 80]
total = 0
for price in prices:
    total = total + price
    print(total)
print("合計", total)
```

**出力**：`200`、`320`、`400`、`合計 400`。

forはリストから要素を順に取り出し、そのたびにpriceへ結び付けて内側を実行します。totalは、その時点までの合計を保ちます。

| 取り出す値 | 加算前のtotal | 加算後のtotal |
| --- | ---: | ---: |
| 200 | 0 | 200 |
| 120 | 200 | 320 |
| 80 | 320 | 400 |

**確認**：`prices = []` にすると、最後の行は？

**答えと理由**：`合計 0`。要素がないのでforの内側を1度も実行せず、初期値0を保ちます。入力の順序を変えても、整数の同じ値を合計するこの例の最終値は同じです。重複した値は、それぞれの要素として加算します。

## 8．rangeとwhile

回数を指定するforの例：

```python
for i in range(3):
    print(i)
```

**出力**：`0`、`1`、`2`。`range(3)` は0から始まり、終了値3を含みません。

条件を確かめ続けるwhileの例：

```python
count = 0
while count < 3:
    print(count)
    count = count + 1
print("終了", count)
```

**出力**：`0`、`1`、`2`、`終了 3`。条件を各回の先頭で評価します。countが3になると条件が偽になり、whileを抜けます。

**確認**：countの更新を削ると？

**答えと理由**：countが0のままなので、条件がずっと成立し、0を繰り返し表示します。実行した場合はターミナルでControl+Cを押して止めます。forの要素の切り替えと違い、このwhileでは自分で終了へ近づく値を更新する必要があります。

## 9．リストの位置と変更

```python
prices = [200, 120, 80]
print(prices[0])
print(prices[-1])
prices[1] = 150
prices.append(50)
print(prices)
```

**出力**：`200`、`80`、`[200, 150, 80, 50]`。

リストは順序を持つ値の集まり。位置を指定するインデックスは0から始まります。負のインデックスは末尾から数え、−1が最後の要素です。要素への代入やappendは、既存のリストを変更します。

**確認**：長さ3の変更前のリストで `prices[3]` を読むと？

**答えと理由**：`IndexError`。使える非負インデックスは0、1、2です。`len(prices)` は要素数3ですが、最後の位置は `len(prices) - 1` です。空リストには末尾の要素もありません。

## 10．同じリストを指す名前

```python
prices = [200, 120]
alias = prices
alias[0] = 999
print(prices)
print(alias is prices)
```

**出力**：`[999, 120]`、`True`。

aliasとpricesは同じリストを指します。aliasから要素を変更すると、その1つのリストの内容が変わります。`is` は同じオブジェクトかを確かめる比較です。`==` は、このリスト同士では内容の等しさを比較します。

**確認**：`alias = [10, 20]` と結び直した後も、pricesがその新しいリストになる？

**答えと理由**：いいえ。aliasという名前の結び付きだけが変わります。「同じリストの要素を変える」と「名前を別のリストへ結び直す」を区別します。

## 11．辞書のキー

```python
order = {"name": "ノート", "price": 200}
print(order["name"])
print("quantity" in order)
print(order.get("quantity", 0))
```

**出力**：`ノート`、`False`、`0`。

辞書は、キーと値の対応を持ちます。`order["name"]` はnameというキーに対応する値を読みます。辞書に対するinは、キーが存在するかを調べます。getは、キーがないときの既定値を指定できます。

**確認**：`order["quantity"]` を読むと？ また、注文課題で個数をgetの既定値0にしてよい？

**答えと理由**：この例では `KeyError`。課題ではquantityが必須なので、不足を0とみなして受け入れてはいけません。キー不足を検出し、仕様どおりValueErrorとして伝えます。getを使う場合も、不足と有効な値の区別を設計します。

## 12．浅いコピー

```python
prices = [200, 120]
copied = prices.copy()
copied[0] = 999
print(prices)
print(copied)
print(copied is prices)
```

**出力**：`[200, 120]`、`[999, 120]`、`False`。

copyは外側の新しいリストを作ります。copiedの0番を別の整数へ置き換えても、pricesの0番は変わりません。ただし、内側にリストや辞書がある場合、その内側まで新しくする処理ではありません。

```python
orders = [{"quantity": 2}]
copied = orders.copy()
copied[0]["quantity"] = 9
print(orders)
```

**出力**：`[{'quantity': 9}]`。新しい外側のリストも、同じ内側の辞書を指しています。

**確認**：注文の入力を変えない関数なら、最初に浅いコピーを作れば十分？

**答えと理由**：コピー後に内側の辞書を変更するなら十分ではありません。今回の集計は、入力を読むだけにし、合計を別の整数として計算できます。

## 13．関数の引数と戻り値

```python
def subtotal(price, quantity):
    return price * quantity

amount = subtotal(200, 2)
print(amount)
print(subtotal(120, 3))
```

**出力**：`400`、`360`。

defは関数を定義します。呼び出しの200と2が引数としてpriceとquantityへ渡ります。returnは計算した値を呼び出し元へ返し、その関数呼び出しを終了します。同じ処理へ別の値を渡せます。

**確認**：returnの直後に、同じ字下げで `print("ここ")` を置くと？

**答えと理由**：そのreturnを実行した呼び出しでは表示しません。returnで関数を抜け、後ろの行へ進まないためです。

## 14．printとreturn

```python
def show_total(price, quantity):
    print(price * quantity)

result = show_total(200, 2)
print(result)
```

**出力**：`400`、`None`。

最初の400は関数内の表示です。この関数はreturnで値を指定していないため、呼び出し元へNoneを返します。画面への出力と、計算に再利用する戻り値は、別の役割です。

**確認**：この後 `result + 10` を計算すると？

**答えと理由**：`TypeError`。resultは整数400ではなくNoneなので、整数10との加算が定義されていません。注文のsummaryは総額を「表示する関数」ではなく、総額の整数を「返す関数」として作ります。

## 15．関数内の名前とスコープ

```python
quantity = 2

def next_quantity(quantity):
    quantity = quantity + 1
    return quantity

print(next_quantity(quantity))
print(quantity)
```

**出力**：`3`、`2`。

スコープは、名前を参照できる範囲に関係します。関数の引数quantityは、関数呼び出し内のローカルな名前です。その名前を3へ結び直しても、外側のquantityの結び付きは変えません。

**確認**：関数なら、リストや辞書を渡しても入力は絶対に変わらない？

**答えと理由**：いいえ。渡されたリストを関数内でappendしたり、辞書の要素を変更したりすれば、呼び出し元からも変更が見えます。ローカル名の結び直しと、共有するオブジェクト自体の変更は別です。入力非変更は、関数という形だけでは保証されません。

## 16．エラーの読み方

例は1つずつファイルへ保存して実行します。途中で例外が出ると、処理がその場所で止まるためです。

| 例 | エラー | 確認すること |
| --- | --- | --- |
| `print(unknown)` | NameError | 名前の定義・綴り |
| `print("3" + 2)` | TypeError | 演算する値の型 |
| `int("abc")` | ValueError | 変換できる値か |
| `[10, 20][2]` | IndexError | 位置が範囲内か |
| `{"price": 200}["quantity"]` | KeyError | キーが存在するか |

構文自体をPythonが解釈できない場合はSyntaxError、字下げの構造が不正ならIndentationErrorなどになります。実行中の例外と、実行前の構文の誤りを区別しましょう。

エラーメッセージは、最後の行で種類と説明を読み、自分のファイル名と行番号が示す箇所へ戻ります。その行に使った値を確認します。型が違った場合は、なぜその型になったかも前の行へ追います。

**確認**：エラー行を削って実行が終われば、修正完了？

**答えと理由**：必要な処理を削っただけかもしれません。期待する値・仕様を満たしたかを、同じ入力で再実行して確かめます。

## 17．入力検証と例外

```python
def checked_quantity(value):
    if type(value) is not int or value < 0:
        raise ValueError("quantityは0以上の整数です")
    return value

print(checked_quantity(0))
print(checked_quantity(True))
```

**結果**：最初に `0` を表示し、次の呼び出しでValueErrorを送出します。エラーで実行が止まることが、この例の期待する結果です。

0は有効な個数です。Trueはboolであり、個数としては受け入れない契約です。Pythonのboolはintの派生なので、`isinstance(True, int)` はTrueになります。ここでは `type(value) is int` によって整数型を厳密に要求します。短絡評価により、型が違えば `value < 0` を実行しません。

**確認**：`def checked_quantity(value: int)` と型注釈だけを付ければ、文字列やboolを拒否できる？

**答えと理由**：できません。型注釈だけでは、Pythonは実行時の入力検証を自動実行しません。仕様に反する値はifで判定してraiseするなど、実際の処理が必要です。assertは自分の検証に使えますが、利用者の入力検証にはifとraiseを使います。

## 18．注文集計へ組み合わせる

小さな例で確かめた知識を、次の関数へまとめます。最初に仕様と期待値を読み、自分で実装してから公開解説例と比較してください。

`summary(orders) -> int` の仕様：

- 入力全体はリスト、各要素は辞書で、name・price・quantityを必須とする。
- nameは文字列。空文字もこの仕様では許す。
- priceとquantityは、0以上の厳密な整数型。bool・小数・数の文字列を拒否する。
- 戻り値は円単位の総額の整数。注文なしは0。
- キー不足、不正な型、負数は、理由が分かるValueErrorを送出する。
- 入力のリストや辞書を変更しない。同じ名前の注文も各行の単価×個数を加算する。

受入例：

```python
orders = [
    {"name": "ノート", "price": 200, "quantity": 2},
    {"name": "ペン", "price": 120, "quantity": 3},
]
assert summary(orders) == 760
assert summary([]) == 0
```

**確認**：760円になる理由と、空の入力が0になる理由は？

**答えと理由**：200×2と120×3の和は400＋360＝760。合計を0から始め、注文ごとに加算する設計なら、空の入力では加算せず0を返せます。

実装は、合計の初期化、forで各注文を読む処理、必須項目・型・範囲の検証、小計の加算、ループ後のreturnへ分けて考えます。returnをループ内に置いた場合、最初の1件しか集計しないので、2件以上の入力で確認します。

## 19．結果と入力非変更を確かめる

正常、空、数量0、負数、文字列、小数、bool、キー不足、入力全体の型違い、要素の型違いを試します。期待値は実装とは独立に、先に手で求めます。異常入力はValueErrorを期待するので、単に「実行が失敗した」とだけ記録しません。

入力非変更を確かめる例。summaryを定義したファイルの末尾などで実行します。`from copy import deepcopy` は、Pythonの標準ライブラリからコピー用の関数を読み込む記述です。

```python
from copy import deepcopy

orders = [{"name": "ノート", "price": 200, "quantity": 2}]
before = deepcopy(orders)
assert summary(orders) == 400
assert orders == before
```

**確認**：beforeを `before = orders` と保存しても、同じ検証になる？

**答えと理由**：なりません。同じリストを指すため、関数が入力を変更するとbeforeからも同じ変更が見え、等しいという比較が通ってしまいます。この検証では、入れ子の辞書を含めて別に保存するdeepcopyを使います。集計関数本体にdeepcopyが必要という意味ではありません。

解説例の実行：

```bash
python3 examples/02-basics/order_summary.py
```

既定の自作データでは総額760円、品目別数量はノート2、ペン3。JSON出力の `total_yen` が総額です。公開例の `summary` は整数だけを返し、`summarize` は品目別数量も含む辞書を返します。2つの戻り値を混同しないでください。

## 概念デモでも確かめる

`concepts.py` は、指定したCASEを1つ実行する補助デモです。本文の短い例とは入力や表示の書式が異なる場合があるので、数値の完全一致だけでなく、そのCASEのコードと状態の変化を照合してください。

```bash

```

このCASEの期待出力：

stepは反復の番号、beforeとafterは加算前後の値です。空入力は反復0回で合計0になります。別のCASEを試すときは、コマンドの最後を次の名前へ置き換えます。

| CASE | 主に確かめる内容 |
| --- | --- |
| rebinding | 整数の再代入と文字列の操作 |

| conversion | 文字列から数への変換 |
| conditions | 比較と分岐 |
| lists | インデックス、共有、コピー |
| shallow-copy | 外側のコピーと内側の共有 |
| dictionary | キーでの読み書き |
| for-trace | 合計の変化と空入力 |
| range | 開始・終了・増分 |
| while-update | 更新と終了条件 |
| functions | 戻り値、表示、ローカル名 |
| exceptions | 例外の種類と原因 |

exceptionsは、意図した例外をデモ内で捕捉して表示するので、終了コードは0です。ValueErrorのtracebackは、実際に得たファイル名・関数名・コード行の抜粋で、絶対パスと行番号を省略しています。通常のエラー全文を読む例では、自分のファイルの行番号も確認してください。
