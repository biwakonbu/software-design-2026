# 第05回 演習：グラフの設計と追跡

学生用。Python 3.12以上を使う。正式な提出方法は授業時の案内に従う。以下は本教材の推奨手順。

## 準備と実演

```bash
mkdir -p work/05
python3 examples/05-graphs/graphs.py
```

参考デモはA-B、A-C、B-D、C-Dを持つ無向グラフと、孤立頂点X。AからDのBFS経路は `['A', 'B', 'D']`。連結成分は2つ。出力と図を照合する。

## 段階1：架空校内マップを作る

次の自作の場所をグラフにする。入口A、受付B、図書室C、演習室D、別棟X。直接行き来できる通路はA-B、A-C、B-D、C-D。Xには通路がない。通路は両方向に通れ、各通路を移動1回として数える。

`work/05/05-map.py` に、全頂点をキーに持つ隣接リストを書く。Xの値は空のリスト。接続を出力し、図と照合する。無向辺は両方の頂点の隣接リストへ記録する。

期待する性質は、Aの隣がBとC、Dの隣がBとC、Xの隣が空であること。無向グラフの次数は、単純グラフであれば隣接頂点の数。Aの次数は2、Xは0。

## 段階2：BFSを手で追う

AからDを探す。Aの隣接順はB、Cとする。頂点をキューへ入れた時点で発見済みにする。開始時点を含め、取り出し1回ごとに次を記録する。

- 取り出した頂点
- 処理後に残るキュー
- 新しく追加した親の記録

Aを取り出した直後のキューはB、C。Bを処理した直後はC、D。Cを処理しても、Dを再追加しない。Dの親はBのまま。この状態からA B Dを復元できるか確認する。

## 段階3：入力を変える

マップのコピーでB-Dを両方向から削除する。AからDへの最少辺数は2のままだが、経路はA C Dになる。さらにC-Dも両方向から削ると、DはAから到達不能になる。元の入力に戻せるよう、変更前後のデータを分けて保存する。

到達可能な頂点を集合として出力する場合、元のグラフでAからの集合はA、B、C、D。XからはXだけ。

## 段階4：有向グラフへの変更

一方通行の仮想通路として、AからB、BからDだけを持つデータを別に作る。AからDには到達できるが、DからAには到達できないことを確認する。

Aの出次数は1、入次数は0。Bの出次数・入次数は両方1。次数の名前を正負の値と混同しない。

移動時間を扱う重み付きグラフへ変えるなら、BFSが最短時間を保証できる条件を `05-design.md` に書く。重み付き最短経路の実装はこの回の必須範囲ではない。

## 提出用の成果物と検証

- `05-map.py`：無向・有向の自作データと出力
- `05-design.md`：頂点・辺・向き・距離の意味、BFS追跡、変更後の期待値と結果

```bash

```
