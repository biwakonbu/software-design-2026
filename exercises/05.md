# 第05回 演習：グラフの設計と追跡

学生用。Python 3.12以上を使います。正式な提出方法は授業時の案内に従ってください。以下は本教材の推奨手順です。

## 準備と実演

```bash
mkdir -p work/05
python3 examples/05-graphs/graphs.py
```

参考デモは、A-B、A-C、B-D、C-Dを持つ無向グラフと、孤立頂点Xです。AからDのBFS経路は `['A', 'B', 'D']`、連結成分は2つです。出力と図を照合してください。

## 段階1：架空校内マップを作る

次の自作の場所をグラフにしてください。場所は、入口A、受付B、図書室C、演習室D、別棟Xです。直接行き来できる通路はA-B、A-C、B-D、C-Dで、Xには通路がありません。通路は両方向に通れ、各通路を移動1回として数えます。

`work/05/05-map.py` に、全頂点をキーに持つ隣接リストを書いてください。Xの値は空のリストにします。無向辺は、両方の頂点の隣接リストへ記録します。接続を出力し、図と照合してください。

期待する性質は、Aの隣がBとC、Dの隣がBとC、Xの隣が空であることです。単純な無向グラフでは、次数は隣接頂点の数です。Aの次数は2、Xは0になります。

## 段階2：BFSを手で追う

AからDを探します。Aの隣接順はB、Cとします。頂点は、キューへ入れた時点で発見済みにします。開始時点を含め、取り出し1回ごとに次を記録してください。

- 取り出した頂点
- 処理後に残るキュー
- 新しく追加した親の記録

Aを取り出した直後のキューはB、Cです。Bを処理した直後はC、Dになります。Cを処理しても、Dは再追加しません。Dの親はBのままです。この状態からA B Dを復元できるか確認してください。

## 段階3：入力を変える

マップのコピーで、B-Dを両方向から削除してください。AからDへの最少辺数は2のままですが、経路はA C Dになります。さらにC-Dも両方向から削ると、DはAから到達不能になります。元の入力に戻せるよう、変更前後のデータを分けて保存してください。

到達可能な頂点を集合として出力する場合、元のグラフでAからの集合はA、B、C、Dです。XからはXだけです。

## 段階4：有向グラフへの変更

一方通行の仮想通路として、AからB、BからDだけを持つデータを別に作ってください。AからDには到達できますが、DからAには到達できないことを確認します。

Aの出次数は1、入次数は0です。Bの出次数・入次数は、どちらも1です。次数の名前を、正負の値と混同しないでください。

移動時間を扱う重み付きグラフへ変えるなら、BFSが最短時間を保証できる条件を `05-design.md` に書いてください。重み付き最短経路の実装は、この回の必須範囲ではありません。

## 提出用の成果物と検証

- `05-map.py`：無向・有向の自作データと出力
- `05-design.md`：頂点・辺・向き・距離の意味、BFS追跡、変更後の期待値と結果
