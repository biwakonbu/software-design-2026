# 第06回 演習：最少移動数の経路を実装する

学生用課題。データ構造とアルゴリズムの知識を確認し、授業内で実装・提出を行う。Python 3.12以上。正式な提出先・締切・参照条件は授業時の案内に従う。以下の成果物構成は本教材の推奨案であり、正式な点数配分は定めない。

## 課題の仕様

架空駅の無向・重みなしグラフを使う。駅はA、B、C、D、E、X。辺はA-B、B-D、A-C、C-E、E-D。Xは孤立駅。

`find_route(graph, start, goal)` は、最少辺数の経路を頂点名のリストで1本返す。既知の駅同士が到達不能なら `None`。未知の駅名、または無向辺として不整合なデータには `ValueError`。既存の入力検証を保ち、仕様の条件を壊さないこと。

同じ駅を指定した場合は `[start]`。辺数は `len(path) - 1`。複数の最短経路がある入力では、1本の妥当な最短経路を返せばよい。このデータのAからDの最短経路はA B D。

CLIは出発駅と到着駅を引数に取る。省略時はA D。成功は終了コード0。到達不能と未知の駅名は終了コード2で、理由がわかるメッセージを表示する。既存のCLIを利用してよい。

## 準備

リポジトリのルートから実行する。

```bash
python3 --version
mkdir -p work/06
cp examples/06-route-project/route_starter.py work/06/route.py
cp examples/06-route-project/route_data.py work/06/route_data.py
python3 work/06/route.py A A
python3 work/06/route.py A B
python3 work/06/route.py A D
```

学生版は同駅と隣駅のみを処理する。A Dは多段経路が未実装なので失敗する。この時点の出力を記録し、実装すべき範囲を確認する。`work/06/route.py` の `find_route` を編集する。

## 段階1：設計を先に書く

`README.md` に、最短の定義、入力の前提、戻り値、終了条件を書く。キュー、親辞書、訪問済み判定の役割を説明する。未知の駅と孤立駅Xを区別する。

## 段階2：BFSを実装する

出発駅をFIFOのキューに入れ、親辞書に `start: None` を記録する。取り出した頂点の隣を調べ、未発見なら親を記録してキューに入れる。到達したgoalから親をたどり、経路を反転して返す。

同じ頂点を重複してキューに入れないこと。到達不能のgoalについて、親の復元を始めないこと。実装の各段階で、小さい入力を使って状態を追う。

## 段階3：必須ケースを検証する

| 入力 | 関数の期待値 | CLIで確認すること |
| --- | --- | --- |
| A D | `['A','B','D']` | 移動数2、正常終了 |
| D A | `['D','B','A']` | 移動数2、正常終了 |
| A A | `['A']` | 移動数0、正常終了 |
| A X | `None` | 到達不能、終了コード2 |
| UNKNOWN D | `ValueError` | 入力エラー、終了コード2 |

隣駅A Bも確認する。自作の小さい入力を1件追加し、手で求めた最短経路と比較する。

```bash
python3 work/06/route.py A D
python3 work/06/route.py D A
python3 work/06/route.py A A
python3 work/06/route.py A X
python3 work/06/route.py UNKNOWN D
```

CLIのエラー後に終了コードを確かめる場合、直後に `echo $?` を実行する。エラー表示は、この2ケースでは想定する結果である。

## 段階4：関数として確かめる

`work/06/check_route.py` を作る。単純なassertでもよいので、CLI表示と関数の結果を分けて確認する。

```python
from route import find_route
from route_data import GRAPH

assert find_route(GRAPH, "A", "D") == ["A", "B", "D"]
assert find_route(GRAPH, "A", "A") == ["A"]
assert find_route(GRAPH, "A", "X") is None
path = find_route(GRAPH, "D", "A")
assert path[0] == "D" and path[-1] == "A"
assert all(b in GRAPH[a] for a, b in zip(path, path[1:]))
print("基本ケースを確認")
```

```bash
python3 work/06/check_route.py
```

期待出力は「基本ケースを確認」。未知の駅の例外検証や、自作入力の検証も自分で加える。上の確認だけですべての仕様を検証したことにはならない。
