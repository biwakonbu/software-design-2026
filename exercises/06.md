## 課題の仕様

架空駅の無向・重みなしグラフを使います。駅はA、B、C、D、E、Xです。辺はA-B、B-D、A-C、C-E、E-Dで、Xは孤立駅です。

`find_route(graph, start, goal)` は、最少辺数の経路を頂点名のリストで1本返します。既知の駅同士が到達不能なら `None` を返します。未知の駅名、または無向辺として不整合なデータには `ValueError` を送出します。配布コードに含まれる入力検証は残し、仕様の条件を壊さないでください。

同じ駅を指定した場合は `[start]` を返します。辺数は `len(path) - 1` です。複数の最短経路がある入力では、妥当な最短経路を1本返せば十分です。このデータでは、AからDの最短経路はA B Dです。

CLIは出発駅と到着駅を引数に取ります。省略時はA Dです。成功時は終了コード0です。到達不能と未知の駅名では終了コード2とし、理由がわかるメッセージを表示します。CLIの処理は、配布コードのものを利用してかまいません。

## 段階2：BFSを実装する

出発駅をFIFOのキューに入れ、親辞書に `start: None` を記録します。取り出した頂点の隣を調べ、未発見なら親を記録してキューに入れます。到達したgoalから親をたどり、経路を反転して返します。

同じ頂点を重複してキューに入れないでください。到達不能のgoalについては、親の復元を始めないでください。実装の各段階で、小さい入力を使って状態を追います。

## 段階3：必須ケースを検証する

| 入力 | 関数の期待値 | CLIで確認すること |
| --- | --- | --- |
| A D | `['A','B','D']` | 移動数2、正常終了 |
| D A | `['D','B','A']` | 移動数2、正常終了 |
| A A | `['A']` | 移動数0、正常終了 |
| A X | `None` | 到達不能、終了コード2 |
| UNKNOWN D | `ValueError` | 入力エラー、終了コード2 |

隣駅A Bも確認してください。自作の小さい入力を1件追加し、手で求めた最短経路と比較します。

```bash
python3 work/06/route.py A D
python3 work/06/route.py D A
python3 work/06/route.py A A
python3 work/06/route.py A X
python3 work/06/route.py UNKNOWN D
```

CLIのエラー後に終了コードを確かめる場合、直後に `echo $?` を実行してください。この2ケースでは、エラー表示が想定どおりの結果です。

## 段階4：関数として確かめる

`work/06/check_route.py` を作ってください。単純なassertでもよいので、CLI表示と関数の結果を分けて確認します。

```python
from route import find_route
from route_data import GRAPH

assert find_route(GRAPH, "A", "D") == ["A", "B", "D"]
assert find_route(GRAPH, "A", "A") == ["A"]
assert find_route(GRAPH, "A", "X") is None
path = find_route(GRAPH, "D", "A")
assert path[0] == "D" and path[-1] == "A"
assert all(b in GRAPH[a] for a, b in zip(path, path[1:]))
print("基本ケースを確認")
```

```bash
python3 work/06/check_route.py
```

期待出力は「基本ケースを確認」です。未知の駅の例外検証や、自作入力の検証も自分で加えてください。上の確認だけでは、すべての仕様を検証したことになりません。
