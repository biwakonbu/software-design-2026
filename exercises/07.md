# 第07回 演習：講評と質疑

学生用。共通のレビューには、本教材が自作した架空提出例を使います。実学生の提出物・評価・個人情報は含みません。自分の第06回の成果物を用意してください。正式な再提出の扱いは、授業時の案内に従ってください。

## 段階1：架空提出例を実行する

この回のグラフは、第06回のデータとは異なります。無向・重みなしの辺はA-B、B-E、E-F、F-D、A-C、C-Dで、孤立頂点Xを含みます。

```bash
mkdir -p work/07
python3 examples/07-review/flawed_route.py A D
python3 examples/07-review/improved_route.py A D
```

架空提出例は、訪問済みを管理したDFSです。最初に得た経路A B E F Dを「最短」と表示し、移動数は4です。改善版はBFSでA C Dを返し、移動数は2です。この違いを、図と出力で照合してください。

`work/07/07-review.md` に、満たしている仕様、満たしていない仕様、反例、改善後に確認する条件を書いてください。経路が実在する点まで誤りと決め付けないようにします。

## 段階2：テストを追加する

同駅A A、孤立駅A X、未知駅UNKNOWN Dを、両方のCLIで試してください。成功時の経路・辺数と、失敗時のメッセージ・終了コードを記録します。XからXは同駅なので、経路X、移動数0となることも確認します。

発展として、作業コピーのグラフからA-Cの辺を両方向に削り、最少経路がA B E F D、4辺になるかを検証します。その結果が得られても、元のDFSが一般に最短を保証するとは言えない理由を書いてください。共有の参考ファイルは変更しないでください。

## 段階3：改善の根拠を書く

「dequeを使ったから」だけで終えず、FIFOで近い層が先に処理されること、未発見の頂点の親を最初の発見時に記録することを説明してください。重みが異なるグラフでは、最少辺数と最少時間が一致するとは限りません。

講評文には、対象の入力、実際の結果、期待する振る舞い、改善後の確認方法を含めてください。能力や人格への評価は避け、コードの振る舞いを扱います。

## 段階4：自分の提出物を説明する

第06回のコードを開き、該当箇所と具体的な入力を使って、次の問いに答えてください。

1. この関数が返す「最短」は、何を最少にした経路か。
2. キューと親辞書は、A Dの探索中にどう変化するか。
3. 同じ頂点がキューへ何度も入らない根拠はどこか。
4. 到達不能と未知の駅名をどう区別したか。
5. 自作テストは、どの実装ミスを検出する狙いで選んだか。
6. AIの提案を採用した箇所について、自分が確認したことは何か。

これらは、担当教員との授業内の質疑で説明します。説明に詰まった場合は、入力を小さくして状態を書き出してください。質疑で気付いた疑問や修正点も記録します。

## 段階5：改善を検証して記録する

`work/07/07-improvements.md` に、第06回の修正前後の振る舞い、再現入力、期待値、実際の結果を書いてください。修正が不要なら、確認した条件とその証拠を記します。AIを使用したか、何に使い、何を自分で検証したかも振り返ります。

成果物の推奨構成は `07-review.md` と `07-improvements.md` です。実装も修正した場合は、修正版コードとテスト結果を一緒に整理してください。提出・再提出の有無は、授業時の案内に従ってください。

## 次回への準備

電卓の入力文字列をどう区切るかを考えてください。例は `12 + 3 * 4` です。数と演算子を識別し、演算のまとまりを木で表す場面を予想します。次回は、字句解析・構文解析・意味解析の区別を学びます。
