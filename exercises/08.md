# 第8回　電卓の解析と実行

## 到達目標

字句・構文・意味の境界を、トークン、AST、テストで説明する。Python 3.12以上、木の走査と関数を復習する。公開referenceはexamples/08-calculator/calculator.py、動作する拡張用starterはstarter.py。Pythonのeval/execを使わない。

## A　トークンの追跡

`12+3.5*(2-1)` を種類・文字列・開始位置に分け、末尾eofも記録する。空白を挿入した場合、意味は同じで開始位置が変わることを確かめる。`2@3` を受理せず、@の位置を説明する。

## B　ASTと評価

`2+3*4`、`(2+3)*4`、`10-3-2` の木を描く。期待値は14、20、5。子の評価が終わるごとに、途中結果を書き込む。

## C　実装または拡張

submission/08に電卓を作り、字句・構文・評価を別関数に分ける。参照版はスライドのEBNF全体に対応する。学生演習の基本必須は整数表記と `3.5` のように小数点の前後に数字がある表記。`3.`、`.5` は発展として実装してもよい。対応範囲をREADMEに明示し、基本例は全て満たす。

`starter.py` は基礎の電卓を呼ぶ動作例。拡張課題は、独立の検査・表示・テストを増やすこと。自力実装する場合も完成例と比較してよい。

受入例：

|入力|期待値または失敗|
|---|---|
|`2+3*4`|14|
|`(2+3)*4`|20|
|`-3*2`|-6|
|`8/2/2`|2|
|`0.1+0.2`|誤差を考慮して0.3に近い|
|`2@3`|字句エラー|
|`(2+3`|構文エラー|
|`2 3`|余分なトークンとして構文エラー|
|`1/0`|評価エラー|

```bash
python3 examples/08-calculator/calculator.py --eval '2+3*4'
python3 -m unittest discover -s submission/08 -v
```

エラーメッセージを出しただけで合格にせず、該当段階をテストする。例を手計算してから実行する。

## 提出物

実装、テスト、README（文法と実行方法）、AST図、reflection（AI採用判断、失敗と修正、段階の説明）をまとめる。提出先・期限は授業の案内に従う。

## 確認

`2+*3`は読めるトークンだが並びが不正。ASTは空白そのものより意味を持つ構造を残す。`10-3-2`は左結合。ゼロ除算は構文として合法な式の評価条件である。自分の処理系で各理由を説明する。
