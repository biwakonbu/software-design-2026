## 段階1 環境の定義

評価関数に環境を渡します。記号は現在の環境から外側へ探し、見つからなければ診断します。`define` は名前の式を評価せず、右辺だけを評価して登録します。定義の返り値は自分の仕様に書き、定義後の名前の値を受入条件にします。

## 段階2 関数

`lambda` は仮引数、本文、定義時環境を保存する値を作ります。呼出し時には実引数を評価し、新しい環境へ束縛します。新しい環境の外側は関数の保存環境とします。引数個数が合わない場合を、束縛前に診断します。

## 段階3 特殊形式

`if` は条件と選択した枝だけを評価します。教材方言では `#f` が偽で、数値 `0` や空リストも真として扱います。`quote` は受け取った式を評価せず返します。通常の関数適用とは別の分岐にします。

## 段階4 再帰とクロージャ

```lisp
(define make-adder
  (lambda (x) (lambda (y) (+ x y))))
(define add5 (make-adder 5))
(add5 3)
```

上の改行は説明用です。教材REPLは1行ごとに1式を読むため、各 `define` のまとまりを1行にして同じセッションへ入力し、`8` を確認します。次のCLIなら改行を含む定義を1個の `begin` として検証できます。

```sh
python3 examples/10-lisp-functions/lisp.py --eval '
(begin
  (define make-adder
    (lambda (x) (lambda (y) (+ x y))))
  (define add5 (make-adder 5))
  (add5 3))'
```

講義の4状態図に対応して、次を追います。G・E5・E3とC0・C5は説明用のラベルであり、自作コードへ同じ名前を追加する条件ではありません。

| 状態 | 作られた値・環境 | 確かめること |
| --- | --- | --- |
| make-adderの定義 | 関数C0がGを保存 | 本文はまだ評価しない |
| make-adder 5の呼出し | x=5のE5、内側の関数C5 | C5がE5を保存する |
| 外側から復帰 | Gのadd5がC5を参照 | 呼出しが終わってもE5へ参照が残る |
| add5 3の呼出し | y=3のE3、外側はE5 | yはE3、xはE5、+はGで検索し8を返す |

呼出しが実行中であることと、環境への参照が残ることを分けて考えます。`add7` を別に作る反例で、異なるxの束縛が混ざらないか確かめます。未完の自作機能は完成参照で理解を確認し、差分を継続実装へ残します。

```lisp
(define fact
  (lambda (n)
    (if (= n 0) 1
        (* n (fact (- n 1))))))
(fact 4)
```

こちらの `define fact` も、REPLには定義全体を1行にして入力します。`fact 0` は `1`、`fact 4` は `24` です。まず小さな `fact 2` で戻る過程を追います。

| 戻る呼出し | 残っていた計算 | 戻り値 |
| --- | --- | --- |
| fact 0 | 停止条件の1 | 1 |
| fact 1 | `(* 1 1)` | 1 |
| fact 2 | `(* 2 1)` | 2 |

下降はn=2、1、0、復帰はn=0、1、2です。各呼出しに別のnの束縛があり、外側には同じfactの定義があります。負数など未対応の入力を、検証済みの範囲と区別します。

## 受入例

| 入力 | 期待 |
| --- | --- |
| `(begin (define x (+ 2 3)) x)` | `5` |
| `(begin (define square (lambda (x) (* x x))) (square 6))` | `36` |
| `(if #f (/ 1 0) 7)` | `7`、ゼロ除算なし |
| `(quote (+ 1 2))` | リスト `(+ 1 2)` |

追加の反例として未定義名、`square` の引数個数違いを記録します。外側の `x = 100` と引数 `x = 4` を共存させ、呼出し後も外側が `100` のままであることを確認します。
