# 第11回演習 スクリプト実行と評価器の準備

## 教材と作業用コード

PythonホストとLisp方言の仕様は本教材の設計上の選択であり、正式シラバスの指定言語仕様ではない。

`examples/11-lisp-scripts/lisp.py` は実行可能な完成参照。`starter.py` は既存機能を使いながら 既存の `square` 組込みへ入力検証を追加するウォームアップ用の実行可能starterで、講義の全機能が未実装の穴埋めではない。ウォームアップでは作業用に複製した `starter.py` の `machine.add_builtin` にあるlambdaを名前付き関数へ置き換え、数値検証の後で負数なら `LispError` を送出する。正常入力と負数の反例を確かめる。`square` はmeta側へ自動登録されない。

本課題は前回の自作版、または別名の作業用コードで進める。完成参照を使った範囲を明記し、自分の実装と混同しない。比較のために参照版をそのまま残す。

演習手順と成果物は教材案。公式の提出先、締切、点数配分をここでは規定しない。

## 到達目標

UTF-8のファイルから複数式を順に実行し、Lisp製評価器に必要なリスト・型・入出力操作を確かめる。

## 段階1 スクリプト入口

第10回の自分の版にファイル実行の入口を加える。ファイル全体をUTF-8で読み、終端まで式を繰り返し読む。同じ環境で順に評価する。ファイルを開けない失敗、読取時の失敗、評価時の失敗を区別する。スクリプトでの失敗後の方針はREADMEに記述する。参照版は実行を停止して非ゼロ終了する。

作業用 `lesson11.lisp` に次を保存する。

```lisp
(define square (lambda (x) (* x x)))
(display (square 5))
(newline)
(display (square 7))
(newline)
```

表示は `25` と `49`。参照版のCLIは最後の式の値だけを自動表示する。この例では末尾の `newline` の返り値 `()` も最後に表示する。途中の値を表示するには `display` と `newline` を使う。

## 段階2 字句の状態

`"hello world"`、`"a;b"`、行コメント `; memo` を試す。文字列中の空白と `;` を失わないことを確かめる。記号と文字列を内部の型で区別する。括弧を文字列内に含めた例も追加する。

## 段階3 リスト操作

`list`、`car`、`cdr`、`cons`、`null?` を使い、空・1要素・複数要素のリストを調べる。空リストから先頭を取る失敗も記録する。

```lisp
(define total
  (lambda (xs)
    (if (null? xs) 0
        (+ (car xs) (total (cdr xs))))))
(display (total (quote (2 3 4))))
(newline)
```

結果は `9`。`total` に空リストを渡すと `0`。

## 段階4 セルフホスティングの準備

Lispの関数へ `(quote (+ 1 2))` を渡し、`car` と `cdr` で式を分解する。数値・記号・リストを判定する操作を試す。次回の評価器で必要になる操作を、対象の式と対応付ける。読取やOS入出力をどの層に任せるかも記述する。

## 受入例

| 入力・状況 | 期待 |
| --- | --- |
| 上の `lesson11.lisp` | `25`、`49`、最後の値 `()` を改行して表示 |
| `(car (quote (10 20)))` | `10` |
| `(cdr (quote (10 20)))` | `(20)` |
| `(cons 5 (quote (10 20)))` | `(5 10 20)` |

加えて、存在しないファイル、括弧不足のファイル、未定義名のファイルを検証する。失敗の段階を説明し、終了状態も記録する。

## 検証コマンド

```sh
python3 examples/11-lisp-scripts/lisp.py lesson11.lisp
python3 examples/11-lisp-scripts/lisp.py --eval '(null? (quote ()))'
```

2行目の結果は `#t`。作業用ファイルを保存した場所から実行し、別の場所で実行する場合はパスを合わせる。
