## 段階1 スクリプト入口

第10回の自分の版にファイル実行の入口を加える。ファイル全体をUTF-8で読み、終端まで式を繰り返し読む。同じ環境で順に評価する。ファイルを開けない失敗、読取時の失敗、評価時の失敗を区別する。スクリプトでの失敗後の方針はREADMEに記述する。参照版は実行を停止して非ゼロ終了する。

作業用 `lesson11.lisp` に次を保存する。

```lisp
(define square (lambda (x) (* x x)))
(display (square 5))
(newline)
(display (square 7))
(newline)
```

表示は `25` と `49`。参照版のCLIは最後の式の値だけを自動表示する。この例では末尾の `newline` の返り値 `()` も最後に表示する。途中の値を表示するには `display` と `newline` を使う。

同じ5個の式を次のように追う。

| 評価の位置 | 共有する大域環境 | 見える出力 |
| --- | --- | --- |
| defineの後 | squareの定義を保持 | まだ表示しない |
| 最初の呼出しの後 | 同じsquareを保持、局所x=5は呼出し内 | 25 |
| 次の呼出しの後 | 同じsquareを保持、局所x=7は別の呼出し内 | 49 |

毎回大域環境を作り直す実装では、最初のdisplayがsquareを見つけられない。参照版の局所引数環境と、式間で共有する環境を区別する。

## 段階2 字句の状態

`"hello world"`、`"a;b"`、行コメント `; memo` を試す。文字列中の空白と `;` を失わないことを確かめる。記号と文字列を内部の型で区別する。括弧を文字列内に含めた例も追加する。

例 `(display "a (b); c") ; memo` で、次の状態を追う。図と同じ名前のstate変数を必ず作る必要はない。参照実装のtokenizeは、文字列を読む内側のループと行末への移動でこの区別を表す。

| 入力部分 | 状態・処理 |
| --- | --- |
| `(display ` | 外側で括弧と記号を確定 |
| 開く引用符 | 文字列内へ入り、蓄積を開始 |
| `a (b); c` | 空白・括弧・セミコロンを文字列に蓄積 |
| 閉じる引用符、`)` | 文字列を確定し、外側で括弧を読む |
| `; memo`、改行 | コメントを捨て、次の行は外側から読む |

結果のトークンは開き括弧、Symbol(display)、文字列 `a (b); c`、閉じ括弧。読取後に記号と文字列の型が別であることも確認する。エスケープした引用符は文字列を閉じず、閉じない文字列は読取エラーになる。状態の詳しい図は `lectures/11.md`、理由と支援の順序は公開補足 `instructor/11.md` にある。

## 段階3 リスト操作

`list`、`car`、`cdr`、`cons`、`null?` を使い、空・1要素・複数要素のリストを調べる。空リストから先頭を取る失敗も記録する。

```lisp
(define total
  (lambda (xs)
    (if (null? xs) 0
        (+ (car xs) (total (cdr xs))))))
(display (total (quote (2 3 4))))
(newline)
```

結果は `9`。`total` に空リストを渡すと `0`。同じ例の途中状態は次のとおり。

| 呼出しで縮むxs | その呼出しが待つ式 | 子から戻る値 | この呼出しの値 |
| --- | --- | --- | --- |
| `(2 3 4)` | `(+ 2 ...)` | 7 | 9 |
| `(3 4)` | `(+ 3 ...)` | 4 | 7 |
| `(4)` | `(+ 4 ...)` | 0 | 4 |
| `()` | null?が真なので0 | 子を呼ばない | 0 |

表の下まで呼び、下から上へ戻る。空のxsではcarを呼ばない。教材のcdrは残りを新しいリストとして返し、元のxsを削除しない。`(cons 5 (cdr (quote (10 20 30))))` は `(5 20 30)`、元の引用データは `(10 20 30)` のまま。

## 段階4 セルフホスティングの準備

Lispの関数へ `(quote (+ 1 2))` を渡し、`car` と `cdr` で式を分解する。数値・記号・リストを判定する操作を試す。次回の評価器で必要になる操作を、対象の式と対応付ける。読取やOS入出力をどの層に任せるかも記述する。
