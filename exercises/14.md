# 第14回演習 Lisp製評価器とREPL

## 教材と作業用コード

PythonホストとLisp方言の仕様は本教材の設計上の選択であり、正式シラバスの指定言語仕様ではない。

`examples/14-selfhosting/lisp.py` は実行可能な完成参照。`starter.py` は既存機能を使いながら 既存の `square` 組込みへ入力検証を追加するウォームアップ用の実行可能starterで、講義の全機能が未実装の穴埋めではない。ウォームアップでは作業用に複製した `starter.py` の `machine.add_builtin` にあるlambdaを名前付き関数へ置き換え、数値検証の後で負数なら `LispError` を送出する。正常入力と負数の反例を確かめる。`square` はmeta側へ自動登録されない。

本課題は前回の自作版、または別名の作業用コードで進める。完成参照を使った範囲を明記し、自分の実装と混同しない。比較のために参照版をそのまま残す。

`evaluator_starter.lisp` は自己評価される数値・真偽値・文字列だけを扱う実行可能な最小starter。`starter-eval 42` の値を確認してから、引用と算術を段階的に追加する。`evaluator.lisp` は完成参照。第14回以降の `repl.lisp` も完成参照である。

演習手順と成果物は教材案。公式の提出先、締切、点数配分をここでは規定しない。

## 到達目標

Lispで書いた対象評価器に、名前、クロージャ、再帰を統合し、Lisp製REPLをPythonホスト上で実行する。継続する環境と、委譲した読取・入出力の範囲を説明する。

## 始める前に

第12回の自作評価器と第13回の未解決記録を用意する。完成参照 `evaluator.lisp` と `repl.lisp` は比較用。自分のファイルで開発し、参照版を編集しない。完成ホストを使う場合、その基盤を明記する。

## 段階1 対象評価器

数値、記号、リストの分類を確認する。`define` の右辺と、`if` の条件・選択枝を対象評価器で処理する。対象の関数は仮引数・本文・定義時環境を保存する。通常の適用で引数を評価してから環境を拡張し、本文を評価する。

## 段階2 クロージャと再帰

対象の `square`、`make-adder`、`fact` を実行する。対象の環境を図にして、呼出しごとの束縛と共有する外側を分ける。再帰では関数自身の定義を環境で見つける必要がある。

```lisp
(define make-adder
  (lambda (x) (lambda (y) (+ x y))))
(define add5 (make-adder 5))
(add5 3)
```

Lisp製REPLへ順に入力すると最後の値は `8`。

## 段階3 Lisp製REPL

Lisp側で読取、対象評価、表示の循環を組み立てる。読取済みS式を対象評価器へ渡し、対象環境を次の入力へ引き継ぐ。読取とOS入出力はPythonホストの組込みへ委譲する。エラーの保護機能もホストを使う。対象評価を、ホストの通常評価で置き換えない。

## 段階4 継続と終了

`define`、正常式、エラー式、正常式の順に入力し、定義が残り、次の入力へ復帰することを確かめる。EOFと `:quit` で終了する。教材REPLは1行ごとに読取る。Lisp製REPLは同じ行の複数式も扱えるが、複数行補完はしないので関数定義は1行にして入力する。

## 受入例

| 対象の入力 | 期待 |
| --- | --- |
| `(begin (define square (lambda (x) (* x x))) (square 6))` | `36` |
| 上の `make-adder` の例 | `8` |
| `(begin (define fact (lambda (n) (if (= n 0) 1 (* n (fact (- n 1)))))) (fact 4))` | `24` |
| `define x=5`、`(+ x 2)`、`(/ 1 0)`、`(+ x 3)` | `7`、診断、`8` |

最後の行の定義は実際には `(define x 5)` と入力する。反例に未定義名、引数個数違い、非選択枝の失敗を含める。

## 完成参照の検証

```sh
python3 examples/14-selfhosting/lisp.py --meta --eval '(+ 1 (* 2 3))'
python3 examples/14-selfhosting/lisp.py --selfhost-repl
```

1行目はLisp製評価器の `m-eval` を実行して `7` を得る。2行目は `repl.lisp` によるLisp製REPLを起動する。無引数の `lisp.py` はホストのREPLであり、起動方法の違いを記録する。
