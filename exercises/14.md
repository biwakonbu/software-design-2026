# 第14回演習 Lisp製評価器とREPL

## 到達目標

Lispで書いた対象評価器に、名前、クロージャ、再帰を統合し、Lisp製REPLをPythonホスト上で実行する。継続する環境と、委譲した読取・入出力の範囲を説明する。

## 授業内の中心と継続作業

当日は同じ `square` を対象式から戻り値まで追い、定義を保つREPLへ接続します。クロージャと再帰の理解確認も行います。名前・関数・REPLの全機能を、最小版から一斉に白紙で実装する時間は想定していません。未完の実装は、確認できた地点から継続して仕上げてください。

以下は授業内の進め方の整理です。この整理によって、提出課題の仕様、受入例、成果物、配点は変わらず、新しい必須機能や提出物も増えません。公式の点数配分は、この教材では規定しません。

## 開始状態と作業の経路

第12回の自作評価器と、第13回の議論記録を用意してください。第13回の討論は、対象の名前やクロージャを全員が完成させたことを意味しません。完成ホストでLispスクリプトが動くことと、自作最小版で数値・引用・四則・分岐のどこまで通るかを確かめてください。

## チェックポイント0 最小式

自作の最小評価器で `42`、`(+ 1 (* 2 3))`、`(quote (+ 1 2))`、`(if #f (/ 1 0) 7)` を確かめてください。期待する値は順に `42`、`7`、`(+ 1 2)`、`7` です。未対応の構文は、そのまま記録します。完成参照での成功と自作版での成功は分けて記録してください。

## チェックポイント1 対象環境

講義の「対象環境の形」「対象の名前検索」を使い、現在の束縛と外側を描いてください。参照の環境は `(frame-cell parent)`、束縛は `(name value)` です。`m-new-env` で空の子を作り、`m-define` で登録し、`m-lookup` で探します。

外側Gの `x = 5` と子Eの `y = 3` を例に、Eで `y` を見つけ、Eにない `x` をGで見つける過程を追ってください。どこにもない名前は診断します。`define` の右辺は、対象評価器で評価してから登録します。ホストの内部名を対象環境で探さないでください。

## チェックポイント2 squareの適用

```lisp
(begin
  (define square (lambda (x) (* x x)))
  (square 6))
```

上の `begin` は1個の対象式です。`--meta --eval` へ、引用した文字列として渡せます。REPLでは定義を1行にして入力してください。

| 順序 | 確かめる状態 |
| --- | --- |
| 先頭と引数の評価 | squareのクロージャと、引数値の列 `(6)` |
| 新しい対象環境 | 保存環境Gを外側にしたE6の `x = 6` |
| 本文 | E6で `(* x x)` を評価。`*` はG、`x` はE6で検索 |
| 復帰 | 値 `36` が呼出し元へ戻る |

仮引数と実引数の個数違いも確かめてください。ここで失敗した場合は、REPLの循環を加えずに評価器を直します。

## クロージャと再帰の確認

```lisp
(define make-adder
  (lambda (x) (lambda (y) (+ x y))))
(define add5 (make-adder 5))
(add5 3)
```

表示用に改行しています。Lisp製REPLへは各定義を1行にして順に入力し、最後の値 `8` を得てください。保存する `x = 5` の環境と、呼出し時の `y = 3` の環境を分けて考えます。第10回の4状態図を、対象環境として読み直してください。

`fact 4 = 24` も、下の受入例で確認してください。各呼出しの別の `n` と、外側で共有する `fact` を区別します。未完の場合は完成参照で過程を確認し、自分の版との差を特定して実装を続けてください。

## チェックポイント3 REPL統合

動く対象評価器へ、読取・対象評価・表示の循環を接続してください。`m-repl` の対象環境を各入力へ渡し、入力ごとに `m-global` で初期化しないでください。`read-all` の結果は式の列なので、`m-sequence` へ渡します。

参照の `guard` は、読取、対象評価、`display`、`newline` を保護します。表示で失敗する場合も、次の入力へ戻ります。読取・入出力・エラー保護・反復機構はPythonホストへ委譲し、対象の意味はLispの `m-eval` と `m-apply` で決めます。

同じセッションで `(define x 5)`、`(+ x 2)`、`(/ 1 0)`、`(+ x 3)` を順に入力してください。値と診断は順に `x`、`7`、ゼロ除算の診断、`8` です。束縛は失敗後も残ります。EOFと単独の `:quit` で終了します。教材REPLは1行ごとに読み、同じ行の複数式を扱いますが、複数行の補完はしません。

## 教材と作業用コード

PythonホストとLisp方言は教材の設計選択であり、正式シラバスが指定する言語仕様ではありません。

- `lisp.py` は完成ホスト、`evaluator.lisp` と `repl.lisp` は完成参照。
- `evaluator_starter.lisp` は自己評価する数値・真偽値・文字列だけの最小starter。統合全体の穴埋めではない。
- `starter.py` は、登録済みのsquare組込みを拡張するウォームアップ用。今回の対象評価器やREPLの開始コードと混同しない。squareはmeta側へ自動登録されない。

ウォームアップは、今回の中心作業を終えてから扱えます。行う場合は、作業用 `starter.py` の `machine.add_builtin` にあるlambdaを名前付き関数へ置き換えてください。数値を検証した後、負数なら `LispError` を送出する分岐を加えます。

公式の提出先、締切、点数配分はここでは規定しません。

## 受入例

| 対象の入力 | 期待 |
| --- | --- |
| `(begin (define square (lambda (x) (* x x))) (square 6))` | `36` |
| 上の `make-adder` の例 | `8` |
| `(begin (define fact (lambda (n) (if (= n 0) 1 (* n (fact (- n 1)))))) (fact 4))` | `24` |
| `define x=5`、`(+ x 2)`、`(/ 1 0)`、`(+ x 3)` | `7`、診断、`8` |

表の最後の行の定義は、実際には `(define x 5)` と入力してください。反例には、未定義名、引数個数違い、非選択枝の失敗を含めてください。

## 完成参照の検証と補足観察

```sh
python3 examples/14-selfhosting/lisp.py --meta --eval '(+ 1 (* 2 3))'
python3 examples/14-selfhosting/lisp.py --selfhost-repl
```

1行目はLisp製評価器の `m-eval` を実行し、`7` を得ます。2行目は `repl.lisp` によるLisp製REPLを起動します。無引数の `lisp.py` はホストのREPLです。起動方法の違いを記録してください。

補足の `python3 examples/14-selfhosting/checkpoints.py` は、付属の完成参照で最小式、対象環境、関数適用、REPLを段階的に観察するためのものです。引数 `minimal`、`environment`、`closure`、`repl` で観察地点を選べます。closureでは同じ環境操作を使って適用を分解し、通常の呼出し結果と比較します。出力を見ただけで、自作版の達成とはしないでください。この補足は、提出条件や採点対象を追加するものではありません。
