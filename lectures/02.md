# 値と型

```python
price = 200         # int: 整数
ratio = 0.1         # float: 浮動小数点数
name = "ノート"     # str: 文字列
available = True    # bool: 真偽値
```

同じ `+` でも、整数なら加算、文字列なら連結になる。

```python
print(200 + 120)    # 320
print("200" + "120")  # 200120
```

---

# 代入と比較

```python
quantity = 2
quantity = quantity + 1
print(quantity)       # 3
print(quantity == 3)  # True
```

`=` は名前と値を結び付ける。`==` は値が等しいか調べる。

**予測**：`quantity == 2` を実行しても、値は変わるだろうか。

---

# 演算子と括弧

```python
print(2 + 3 * 4)     # 14
print((2 + 3) * 4)   # 20
print(7 // 2)        # 3
print(7 % 2)         # 1
```

括弧で計算の意図を示す。`/` と `//` は役割が異なる。<br>
金額の例は円単位の整数とし、端数処理を持ち込まない。

---

# 条件分岐と境界

```python
quantity = 0
if quantity < 0:
    print("個数は0以上にしてください")
elif quantity == 0:
    print("注文なし")
else:
    print("注文あり")
```

境界の `-1`、`0`、`1` を試す。インデントが処理の範囲を決める。

---

# リストは順序のある集まり

```python
prices = [200, 120, 80]
print(prices[0])     # 200
print(len(prices))   # 3
prices.append(150)
```

添字は0から始まる。存在しない添字は `IndexError`。<br>
`[]` も有効なリスト。空の場合の扱いを考える。

---

# 反復で合計を作る

```python
prices = [200, 120, 80]
total = 0
for price in prices:
    total = total + price
print(total)  # 400
```

| 反復後 | 1回目 | 2回目 | 3回目 |
|---|---:|---:|---:|
| total | 200 | 320 | 400 |

# rangeと反復回数

```python
for index in range(3):
    print(index)
# 0, 1, 2 を順に出力
```

`range(3)` の終端3は含まない。

**実験**：`range(0)`、`range(1, 4)` の出力を予測して試す。

---

# 辞書はキーで値を取り出す

```python
order = {"name": "ノート", "price": 200,
         "quantity": 2}
subtotal = order["price"] * order["quantity"]
print(subtotal)  # 400
```

添字の位置でなく、意味のあるキーで項目を表す。<br>
存在しないキーの参照は `KeyError` になる。

---

# 複数の注文を表す

```python
orders = [
    {"name": "ノート", "price": 200, "quantity": 2},
    {"name": "ペン", "price": 120, "quantity": 3},
]
total = 0
for order in orders:
    total += order["price"] * order["quantity"]
print(total)  # 760
```

リストが注文の集まり、辞書が1件の注文を表す。

---

# 関数の入力と出力

```python
def subtotal(price: int, quantity: int) -> int:
    return price * quantity

amount = subtotal(200, 2)
print(amount)  # 400
```

`return` で結果を呼び出し元に返す。型注釈は意図を伝える。<br>
型注釈だけでは、実行時の入力検証は行わない。

---

# printとreturnの違い

| 操作 | 結果の行き先 | 次の計算に使う |
|---|---|---|
| `print(400)` | 画面へ表示 | 戻り値は `None` |
| `return 400` | 呼び出し元へ | 数値400を使える |

表示と計算を分けると、画面がなくても関数をテストできる。

---

# 仕様を例にする

```python
assert subtotal(200, 2) == 400
assert subtotal(200, 0) == 0
assert subtotal(0, 3) == 0
```

通常の例と境界の例を用意する。失敗した例が修正の手掛かりになる。

> `assert` は学習・テスト用。入力検証には明示的な条件分岐を使う。

# 入力の契約

この教材の注文は、単価と個数が **0以上の整数**。

```python
def checked_subtotal(price, quantity):
    if (type(price) is not int
            or type(quantity) is not int):
        raise ValueError("単価と個数は整数")
    if price < 0 or quantity < 0:
        raise ValueError("単価と個数は0以上")
    return price * quantity
```

Pythonの `bool` は `int` の派生型。ここでは真偽値を受け付けない。

# 例外と回復

```python
text = "two"
try:
    quantity = int(text)
except ValueError:
    print("整数を入力してください")
else:
    print(quantity)
```

回復できる失敗を扱う。原因を隠すために全例外を握りつぶさない。

# 変更が共有されるリスト

```python
a = [200, 120]
b = a
b.append(80)
print(a)  # [200, 120, 80]
c = a.copy()
c.append(150)
```

`a` と `b` は同じリストを参照する。`copy()` は浅いコピー。<br>
入れ子のリストや辞書まで複製するとは限らない。
