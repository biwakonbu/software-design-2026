# 対象式の分類

数値・文字列・真偽値、記号、リストを分類する。

# 対象環境の形

```mermaid
flowchart LR
  E["env: (frame-cell parent)"] --> F["frame-cell: (bindings)"]
  F --> B["bindings: ((x 5) (y 3))"]
  E --> P["parent: 外側の対象環境"]
```

参照版は束縛を入れたセルと外側への参照を持つ。
環境の形式を、検索・定義・拡張の関数で隠す。

---

# 環境を作る操作

```lisp
(define m-new-env
  (lambda (parent) (list (list '()) parent)))
(define m-bindings
  (lambda (env) (car (car env))))
```

完成参照の定義を抜粋。新しい環境は空の束縛と指定した外側を持つ。
`m-bindings` は現在の環境の束縛を取り出す。

---

# 対象の名前検索

```mermaid
flowchart LR
  E["E: y = 3"] -->|外側| G["G: x = 5"]
```

Eで `y` を探すと `3`。Eにない `x` はGで見つかり `5`。

どこにもない名前は診断する。ホスト環境から探さない。

---

# 対象の定義

```lisp
(m-define (car args)
  (m-eval (m-second args) env (+ depth 1))
  env)
```

`define` 分岐の登録処理を抜粋。右辺を対象評価器で評価してから登録する。
対象の `(define x (+ 2 3))` は、現在の対象環境に `x = 5` を置く。

---

# 定義と共有セル

クロージャは、作成時の対象環境への参照を保存する。

`m-define` は共有するframe-cellの束縛を更新する。

同じ環境を参照する関数は、後から登録した自分の名前も検索できる。

---

# 対象のsquare

```lisp
(define square
  (lambda (x) (* x x)))
(square 6)
```

対象大域環境Gで定義し、Lisp製評価器で呼び出す。
改行は表示用。REPLへは各定義を1行にして入力する。

# クロージャの生成

```lisp
(list 'closure (car args) (cdr args) env)
```

`env` はホストの環境でなく、`m-eval` の引数である対象環境。

# 対象の再帰

```lisp
(define fact
  (lambda (n)
    (if (= n 0) 1
        (* n (fact (- n 1))))))
(fact 4)
```

結果は `24`。各呼出しは別の `n`、外側には同じ `fact` の定義。

# REPLへ渡す状態

```mermaid
flowchart LR
  R["m-repl(env)"] --> S["m-sequence(forms, env, 0)"]
  S --> E["m-eval(form, env, depth)"]
```

同じ対象環境を各入力へ渡す。
入力のたびに `m-global` を呼ぶと、前の定義が消える。

---

# 循環の順序

<table>
<thead><tr><th>順序</th><th>処理</th></tr></thead>
<tbody><tr><td>入力</td><td><code>read-line</code> で1行を読む</td></tr><tr><td>終了判定</td><td>EOFまたは単独の <code>:quit</code> なら終了</td></tr><tr><td>保護した処理</td><td>読取・対象評価・結果表示を <code>guard</code> で保護</td></tr><tr><td>次の入力</td><td>診断後も同じ対象環境で続ける</td></tr></tbody>
</table>

反復機構はホストの `while` を使う。

# 読取と対象評価

```lisp
(m-sequence (read-all line) env 0)
```

`read-all` はPython側の字句・構文解析へ委譲する。

式の列の実行順序は `m-sequence`、式の意味は `m-eval` が決める。

---

# guardの範囲

```lisp
(define outcome
  (guard (lambda ()
    (display (m-sequence (read-all line) env 0))
    (newline)
    #t)))
```

参照 `m-repl` の抜粋。読取・評価だけでなく表示も保護する。
成功なら先頭が `#t`、失敗なら `#f` と診断を含む値を得る。

---
