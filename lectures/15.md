# 講評の対象

コードだけでなく、仕様、受入例、実行ログ、説明を扱います。

動いた結果と、その結果になる理由を結び付けます。

ここでの観点は授業用の案であり、正式な点数配分ではありません。
---
class: learning-course
---


# 講評の進め方

作者は達成した機能と、未対応の機能を説明します。

聞き手は小さな入力で判断を確かめます。

作者は指摘を受け、改善を1つ選びます。

ペアで作者と聞き手を交代します。共通講評の後も、各人のデモと質問の時間を残します。

# 例B 環境の混同

関数の呼出しごとに、同じ変数表へ引数を書き込む架空の案です。

`f` の引数が、外側の変数を上書きしてしまいます。

正常な一例だけではこの誤りを見落とします。

# 例Bの反例

```lisp
(define x 100)
(define f (lambda (x) (+ x 1)))
(f 4)
x
```

本教材の仕様では結果は `5` と `100` です。

作者は検索する環境と更新する環境を説明します。

例Bの単一表の案で、`(f 4)` の後に `x` を評価した値を予想してください。
